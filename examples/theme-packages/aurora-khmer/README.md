# Aurora Khmer Test Theme

This is a development package for testing Wattaman's server-side theme ZIP upload.

Suggested catalog settings:

- Name: Aurora Khmer
- Kind: Theme
- Mode: Light or Dark
- Primary color: `#14B8A6`
- Secondary color: `#FBBF24`
- Font: Inter
- Radius: Soft

The generated ZIP intentionally contains only `style.css`, because the current first implementation slice accepts the stylesheet and referenced image/font assets but does not yet process `theme.json`, README, or screenshots inside theme archives.
